# ClassTrack

ClassTrack is an intelligent Class Attendance & Reminder application for Android, built to help students manage their academic life with precision and style.

## 🚀 Features
- **Dynamic Timetable**: Easily manage your classes with full edit and delete support.
- **Smart Double-Alarms**: Get notified both at a lead time (15-45 mins before) and exactly when class starts.
- **Attendance Analytics**: Real-time tracking with decision support logic (Safe to skip vs. Critical).
- **Material 3 Design**: A premium Emerald/Slate aesthetic with smooth animations and intuitive UI.
- **Customizable Experience**: Set your own alarm sounds, volume, and profile details.

## 🛠 Tech Stack
- **Native Android (Java)**
- **Room Database** (Local Storage)
- **Material Design 3** (UI/UX)
- **AlarmManager API** (Precision Scheduling)
